# GameZone Website

Dự án **GameZone Website** giới thiệu trò chơi và thực hành *PowerShell, Markdown*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---------|----------|
| docs | Tài liệu dự án |
| media | Hình ảnh và logo |
| data | Dữ liệu dự án |
| logs | Nhật ký và báo cáo lỗi |
| backup | Bản sao lưu file |

## Liệt kê nội dung dự án

```powershell
Get-ChildItem -Recurse -Force
```
